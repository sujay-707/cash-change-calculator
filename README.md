# 💰 Cash Change Calculator

A fully responsive **Cash Change Calculator** web application that calculates the exact change to return and shows the minimum number of currency notes required.

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 📖 How It Works
1. Enter the **Total Bill Amount**
2. Enter the **Cash Given by Customer**
3. Click **Calculate Change**
4. View:
   - Total change to return
   - Note-wise denomination breakdown
